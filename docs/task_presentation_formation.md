# Tâche : Ajout de la Page de Présentation de la Formation IA

## Objectif
Créer une page de présentation pour la formation "Donnez vie à vos idées : Créez vos propres outils grâce à l’IA".
Cette page doit contenir :
- Le texte fourni par l'utilisateur.
- Une image représentative.
- Un bouton d'inscription ouvrant une popup.
- Une popup avec les champs : Nom, Prénom, Email (obligatoires), Numéro de téléphone (facultatif).

## Étapes
1.  [ ] Analyser la structure du projet.
2.  [ ] Lire les documents de référence si présents (`ortho_psy.pdf`).
3.  [ ] Générer une image pour la formation.
4.  [ ] Créer la route `src/app/formation-ia`.
5.  [ ] Implémenter la page avec le design et le contenu.
6.  [ ] Implémenter le composant Modal pour l'inscription.
7.  [ ] Styliser la page.
8.  [ ] Vérifier `docker-compose.yml`.
